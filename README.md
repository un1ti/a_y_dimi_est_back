# a_y_dimi_est_back
# Scientific Arbitrator — Backend

Серверная часть системы интеллектуального анализа научных публикаций.

Backend обрабатывает PDF-документы, извлекает научные данные, сравнивает исследования и формирует ответы с доказательствами из источников.

## Технологии

- Python + FastAPI
- SQLite для хранения данных
- RAG для поиска релевантных фрагментов
- Ollama + Qwen для локальной работы с LLM
- REST API для связи с Frontend

## Как работает

1. **Загрузка PDF.** Сервер принимает научные публикации.
2. **Извлечение данных.** Система получает текст, метрики, таблицы и сведения об экспериментах.
3. **RAG.** Находит фрагменты документов, связанные с запросом пользователя.
4. **LLM.** Qwen анализирует найденный контекст и формирует объяснение.
5. **Проверка доказательств.** Система связывает выводы с исходными документами, страницами и фрагментами.
6. **Результат.** Backend возвращает данные через API, включая возможность экспорта в CSV.

## Запуск

Требуются Python и установленные зависимости.

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его и установите зависимости:

```bash
pip install -r requirements.txt
```

Для локального AI установите Ollama и загрузите используемую модель Qwen.

Запустите Backend командой, указанной в конфигурации проекта.

Документация API при стандартной настройке FastAPI доступна по адресу:

```text
http://localhost:8000/docs
```

## Назначение

Backend отвечает за обработку публикаций, хранение результатов, поиск доказательств и взаимодействие с нейросетью.

**Важно:** система помогает анализировать научные результаты, но не заменяет экспертную проверку достоверности исследований.
